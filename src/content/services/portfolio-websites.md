A portfolio has a specific problem to solve: proving capability quickly to someone who is
skimming. That means large, fast-loading imagery, restrained interface chrome, and enough
context to show how you think without turning every project into an essay.

I build these on content collections so publishing a new project is a matter of adding a file
with your images and notes — no CMS licence, no database, no maintenance overhead.

Image handling gets particular attention. Modern formats, correct sizing per breakpoint and
lazy loading mean a visually rich portfolio that still loads almost instantly on mobile data.
