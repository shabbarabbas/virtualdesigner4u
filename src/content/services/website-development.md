The development phase is where most projects quietly accumulate the problems that surface a
year later — a plugin that breaks on update, a layout that collapses on a device nobody
tested, a codebase the next developer refuses to touch.

I build to avoid exactly that. Markup is semantic first, styled second. JavaScript is added
where it earns its place rather than by default. Everything is componentised, so the fifteenth
page costs a fraction of the first.

Performance is treated as a requirement rather than a final polish pass. Budgets are set at
the start and checked continuously, which is why my builds land at 95+ Lighthouse scores
without any last-minute scrambling.
